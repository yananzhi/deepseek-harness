# 编译安装（本机 runbook）

本页只记录这台 Windows 机器上的安装与编译步骤；通用贡献者流程见 [development.md](development.md)，测试分层见 [testing.md](testing.md)。

## 环境

Node 使用 `C:\Program Files\nodejs` 下的 22.x；PATH 默认的 Node 20 会导致构建失败或服务静默不起。启动器从仓库根 `.env` 读 `node_dir` 与 `launch_*`；代理变量放在 Windows 用户环境变量里，不进仓库 `.env`。

## 安装依赖

本机出站代理（`127.0.0.1:18889`）把 registry 下载限到约 8 KB/s，大包装不完；直连国内镜像是 MB/s 级（腾讯 1.3、npmmirror 3.2、华为 4.5），因此安装时绕开代理并指定镜像：

```sh
HTTP_PROXY= HTTPS_PROXY= http_proxy= https_proxy= NO_PROXY='*' pnpm install --registry https://registry.npmmirror.com
```

`pnpm-workspace.yaml` 的 `minimumReleaseAgeExclude` 已豁免 pi-ai 等包；若供应链年龄检查因超时误杀，追加 `--config.minimumReleaseAge=0`。`@deepseek-ai/libreoffice-kit-win32-x64`（117 MB，可选原生包）在本网络下装不下来；缺 `simple-icons` 则客户端构建缺模块，需要先把它装进 store。

## 编译

```sh
pnpm run build
```

产物为 `apps/cli/lib/bin.js` 与 `apps/web/dist`，以及各包 `lib/`。改动面可用 `tsc -b <pkg>` 与对应 `*.spec.ts` 先验证，再全量构建。

## 启动与验证

`start.bat` 以 `.env` 的 `launch_*` 启动 `node apps/cli/lib/bin.js --profile <launch_profile>`，就绪 URL（含 per-boot token）打印在 `logs/dsh-<profile>.out.log`。直接改 `node_modules` 内文件的改动会被 `pnpm install` 还原，改完后需重启进程。
